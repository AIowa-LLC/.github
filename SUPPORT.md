# Support

For project-specific help, start in the repository where the issue occurs.

## Bugs

Use the repository's bug report form and include:

- what you expected
- what happened
- reproduction steps
- environment or version information
- relevant logs or screenshots with secrets removed

## Feature requests

Use the repository's feature request form. Describe the problem first, then the proposed solution.

## Questions

If a repository has Discussions enabled, prefer Discussions for usage questions and open-ended ideas.

## Private matters

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
